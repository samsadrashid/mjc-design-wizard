# Parcelo (SYNTHETIC TEST PROJECT)

Parcelo is a fictional parcel-tracking and pickup-point app with a React web app and a React Native app.
This project exists only to test the mjc-design-wizard skills. Every person, number, company, and
address in it is invented. Do not treat any of it as real.

- Status: v1.4 is live. Team size, deadlines, and budget are not documented.

- Research notes: research/interviews/
