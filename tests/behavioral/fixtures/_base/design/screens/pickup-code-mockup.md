# Mockup description: pickup code screen (synthetic, proposal under review)
Goal stated by designer: "Help a recipient find and show their pickup code in under a few seconds."
Target user stated by designer: recipients who collect from a pickup point.
Layout: a green full-width banner at the top reading "Great news, your parcel is ready!" (about a third of the screen),
then a small gray code (14px) below the fold, then a large "Share" button, then a small text link "Copy code".
States shown: default only. Error, expired, and offline states are not shown.
