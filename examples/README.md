# Examples

Each example shows a prompt, invented sample input, the skill's behavior, and the shape of its output.

**All examples are illustrative.** Inputs, numbers, findings, and project details are invented sample data. None comes from a real product, study, or dataset, and none shows measured skill performance. An example shows what the contract asks for; it does not show that a skill reliably produces it. For behavioral evidence, see [tests/behavioral/](../tests/behavioral/).

Most examples follow one fictional product, Kettle, a meal-kit subscription web app, so outputs can reference each other (for example, the journey map uses the persona). Four examples use their own invented scenarios.

Each output block uses the skill's exact output headings and starts with the `> skill:` metadata line. Dates appear as `<YYYY-MM-DD>` because the skill takes the real date from the session. The validator checks these conventions (see [CONTRIBUTING.md](../CONTRIBUTING.md)).
